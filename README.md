# Bayan
Bayan is a mobile application designed to bring people closer through better communication. It allows deaf and non-verbal users to express themselves using sign language, translated into text or speech. Hearing users can reply using voice or text which is clearly visualized for deaf users.
***
## Project Idea
Allowing deaf and non-verbal users to express themselves using sign language, translated into text or speech. Hearing users can reply using voice or text which is clearly visualized for deaf users.
